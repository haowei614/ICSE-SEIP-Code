## 发给对方（中文）

你好，

我们在做一项关于**本地部署开源大模型做需求工程（RE）任务**的实证研究（目标投稿 ICSE SEIP）。想请你做一次**半结构化访谈（约 30–45 分钟）**，帮我们审一版「在什么约束下、哪类任务可以本地化」的**部署决策表**。

### 这不是问卷
- 不统计「同意比例」当结论  
- 我们要的是：你觉得哪一格不合理、为什么、应改成什么  
- 笔记会**匿名化**；不写公司名、不写可识别项目信息（除非你明确允许）

### 适合谁
做/审过需求、规格、追溯、质量门禁，或在 NDA / 数据驻留 / 气隙 / 成本约束下评估过 LLM 落地的工程师（汽车/嵌入式/工业软件尤佳，其他领域也可）。

### 你会看到什么
1. 简短背景：为何有时不能走云 API  
2. **4 个真实失败样例**（公开数据集上的模型输出；不是你们公司的数据）  
3. 一张**临时决策表**（任务类型 × 约束 → 是否允许本地化）  
4. 请你说：现有审查流程能不能在约 60 秒内抓住这类错误；表上哪格要改

### 时间与形式
- 30–45 分钟，线上或当面均可  
- 可选：会前扫一眼 1 页背景（我们发给你）  
- 不需要准备材料，不需要会用我们的工具

### 若你愿意
请回复：方便的时间段 + 你更熟的领域（需求分类 / 追溯 / 质量体系 / 部署任一即可）。  
非常感谢！
